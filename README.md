# Employee Management System (EMS)

A simple Employee Management System built with pure PHP — no frameworks, no database. All records are stored in flat JSON files using PHP's File System functions, with Sessions handling authentication.
The project was built to practice the fundamentals of PHP: file handling (CRUD on JSON), sessions, form validation, file uploads, and organizing a project into a clean, maintainable folder structure.
Features
•	Authentication — register, login, and logout using sessions
•	Employees CRUD — list, create, update, and delete employees
•	Form Validation — server-side validation for all inputs
•	Protected Routes — management pages require a logged-in session
Tech Stack
Language: PHP (procedural, no framework)
Storage: JSON files (File System APIs)
Styling	: Bootstrap 5
Sessions: PHP native sessions
No database is required — this is intentional, as part of the learning goals.
